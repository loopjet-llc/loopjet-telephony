# Loopjet upstream mirror

This repository tracks [frappe/telephony](https://github.com/frappe/telephony)
on `develop`. Telephony is a required dependency of Frappe Helpdesk v1.27.0.

The upstream project does not currently publish releases or tags. Loopjet uses
reviewed dated tags for reproducible application images. The `develop` branch
fast-forwards daily but does not automatically change the production version lock.
